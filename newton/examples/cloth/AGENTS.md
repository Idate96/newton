# Cloth Examples Guide

This folder contains cloth-focused demos ranging from simple hanging setups to Style3D and robot interaction examples.

## What Lives Here

- Hanging, bending, twist, rollers, poker-card style interactions, and articulated manipulation of cloth.

## Expectations

- Be explicit about which solver path the example is exercising.
- Keep cloth examples visually diagnostic. These demos are often used to catch regressions that unit tests do not make obvious.
- If you change cloth solver behavior or cloth import workflows, update these demos and their screenshots deliberately.

## Validation

- Run cloth-related tests and the changed example regression.
