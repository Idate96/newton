# Contacts Examples Guide

This folder demonstrates contact-heavy rigid-body scenarios.

## What Lives Here

- Brick stacking
- Pyramid stacking
- Nut-and-bolt setups using hydroelastic or SDF contacts

## Expectations

- Use these examples to keep contact behavior interpretable. They are good canaries for collision-pipeline changes.
- If a geometry, contact, or solver change makes one of these examples less stable, investigate rather than updating screenshots blindly.

## Validation

- Run relevant collision, contact, hydroelastic, and example-regression tests.
