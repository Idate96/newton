# Cable Examples Guide

This folder demonstrates cable and cable-like deformation scenarios.

## What Lives Here

- Twist, pile, Y-junction, and bundle-hysteresis examples.

## Expectations

- Keep the scenario clear about what physical behavior is being demonstrated.
- These examples are sensitive to solver and collision behavior. Treat visual or stability changes as real regressions until proven otherwise.

## Validation

- Run cable-related tests and the affected example regression.
