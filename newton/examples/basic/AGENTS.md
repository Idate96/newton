# Basic Examples Guide

This folder holds the first-stop examples for core Newton workflows.

## What Lives Here

- Primitive shapes, joints, pendulums, URDF import, heightfields, viewer-only rendering, recording, replay, and plotting.

## Expectations

- Prefer simple, teachable examples over feature-dense demos.
- Use public APIs such as `ModelBuilder`, public solver classes, and public viewer classes.
- When a new core workflow becomes important to users, add or update a basic example before hiding it only in advanced demos.

## Maintenance

- Keep these examples lightweight and easy to run.
- If a public API rename breaks basic examples, update them in the same change as the API change.
