# Softbody Examples Guide

This folder demonstrates deformable solids and manipulator interaction with soft bodies.

## What Lives Here

- Hanging soft body
- Softbody manipulation with Franka

## Expectations

- Keep mesh or tet-based setup readable.
- Changes here often involve geometry import, solver behavior, and viewer rendering together.
- If the deformation behavior changes visually, treat it as a likely regression until checked against tests and intent.

## Validation

- Run softbody-related tests and the changed example regression.
